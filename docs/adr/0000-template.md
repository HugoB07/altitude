# ADR-0000 - Template

- **Status:** proposed | accepted | superseded by [ADR-XXXX](XXXX-title.md)
- **Date:** YYYY-MM-DD
- **Deciders:** who agreed to this

## Context

What forces this decision? Constraints, requirements, and what breaks if we do nothing.
State facts, not preferences.

## Decision

What we are doing, stated plainly and in the present tense.

## Alternatives considered

| Option | Why it was rejected |
| ------ | ------------------- |
| …      | …                   |

Rejecting an option is as informative as choosing one. Record it so the same debate does
not reopen in six months.

## Consequences

What becomes easier, what becomes harder, and what we now have to live with. Include the
costs - an ADR listing only benefits is a sales pitch, not a decision record.

## Revisit if

The concrete condition that would make this decision worth reopening. If no such
condition exists, say so.
