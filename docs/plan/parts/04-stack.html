4.5 Monorepo

# pnpm workspaces + Turborepo
altitude/
├─ apps/
│  ├─ web/                 # Next.js 16 — UI + Route Handlers + Server Actions
│  ├─ worker/              # Node — pg-boss, cron, no dependency on Next
│  └─ docs/                # Fumadocs — public documentation
├─ packages/
│  ├─ db/                  # Drizzle schema, SQL migrations, seeds, RLS
│  ├─ core/                # pure domain: ledger, valuation, performance, authorisation
│  ├─ importers/           # CSV/XLSX/OFX/QIF/CAMT + presets + fixtures
│  ├─ connectors/          # Connector interface + optional implementations
│  ├─ market-data/         # quote and FX providers, cache, fallback
│  ├─ ui/                  # shadcn + Magic UI + charts + design tokens
│  └─ shared/              # types, Zod, Money/Decimal, errors, constants
├─ tools/
│  ├─ cli/                 # altitude backup|restore|recompute|import|doctor
│  └─ fixtures/            # demo data generator
├─ docker/                   # Dockerfile, compose, entrypoint, healthcheck
└─ docs/adr/                 # architecture decision records
Decision — packages/core depends on neither Next, nor React, nor HTTP

This is the rule that keeps the project testable and durable: the domain is tested in milliseconds with Vitest, without a browser or a server. It is machine-checkable with dependency-cruiser in CI. If Next.js changes paradigm tomorrow, you rewrite apps/web, not the business logic.

4.6 Cross-cutting concerns

Logging
pino in JSON, one correlation id per request, automatic redaction of amounts, IBANs and tokens at info level.
Error tracking
Self-hostable Sentry or GlitchTip, disabled by default. No financial data in the error context.
Metrics
/api/health (liveness/readiness) plus an optional token-protected Prometheus /metrics endpoint.
Email
nodemailer with operator-supplied SMTP. React Email templates. No sending at all if SMTP is unconfigured (silent degradation, not an error).
Files
A Storage interface with two implementations: local disk (default) and S3-compatible. Import files kept 30 days by default, configurable.
Search
pg_trgm + unaccent over transaction descriptions and instrument names. No external engine.
Encryption
Application-level AES-256-GCM for connector secrets, master key in ALTITUDE_ENCRYPTION_KEY (Docker secret), envelope encryption with a per-record key. See §7.8.
