12.2 The Globe - specification

Data
  • One server query returns [{ iso2, lat, lng, value, pct, label }], capped at 60 countries; the rest is grouped as "other".
  • Marker radius ∝ √(weight) - so perceived area stays proportional to value.
  • Colour by region (North America, Europe, Asia-Pacific, emerging), consistent with the other allocation charts.
  • A ring around the globe shows the share that could not be looked through.
  • Country centroids: an embedded dataset (~4 kB), no network call.
Constraints
  • Lazy loading: next/dynamic plus IntersectionObserver. The globe must not weigh on the dashboard's first paint.
  • Reduced motion: under prefers-reduced-motion, rotation is disabled and the render is static.
  • Accessibility: an equivalent sorted table is always present below the globe, not hidden behind a tab. The globe is decorative in ARIA terms; the data lives in the table.
  • Fallback: if WebGL is unavailable, an equirectangular SVG map takes over.
  • Interaction: hover → country / amount / percentage tooltip. Click → filters the table to that country.
  • Performance: ≤ 16 ms per frame on a mid-range laptop; animation stopped when the tab is hidden.

12.3 Design tokens

/* Semantic, never literal: "gain" rather than "green" */
--gain: oklch(0.62 0.15 155);    --loss: oklch(0.58 0.19 25);
--neutral: oklch(0.55 0.02 260); --estimated: oklch(0.72 0.04 260);
/* Asset classes - a stable palette, reused by EVERY chart */
--ac-equity --ac-bond --ac-cash --ac-crypto --ac-realestate --ac-alt
  • An asset keeps the same colour in the pie chart, the stacked area, the treemap and the globe. Without that rule, users must re-read the legend on every chart.
  • Gain and loss are never encoded by colour alone: explicit sign, arrow and label. Around 8% of men have a red-green colour vision deficiency.
  • Figures use font-variant-numeric: tabular-nums: columns of amounts must line up.
  • Light and dark themes are peers, never a dark theme bolted on by inversion.

12.4 Privacy mode

Ctrl/⌘ + Shift + H replaces every amount with ••••• while percentages and charts stay readable. Essential for a screenshot, a demo or a train journey. The state persists per device (local storage) and is not synchronised.

Security, privacy, GDPR

Security

An Altitude instance holds a complete map of a household's wealth. That is a valuable target: the threat model must be explicit, not implicit.

13.1 Threat model

ScenarioLikelihoodImpactCountermeasures
Instance exposed to the internet without hardeningHighCriticalHTTPS enforced by Caddy, 2FA strongly prompted at setup, rate limiting on authentication, progressive lockout, a visible warning until 2FA is enabled.
Weak or reused passwordHighCriticalArgon2id, 12-character minimum, checking against breached-password lists (offline, k-anonymity), passkeys offered first.
Stolen backup or diskMediumCriticalConnector secrets encrypted with a key held outside the database; documentation pushes volume encryption; backups encrypted by default in the supplied tool.
XSS through an imported transaction descriptionMediumHighReact escaping by default, no dangerouslySetInnerHTML on user data, strict CSP without unsafe-inline.
SSRF via a user-supplied URLLowHighDomain allow-list for providers, controlled DNS resolution, private ranges blocked, no redirect following outside the list.
Cross-household leakLowCriticalTwo barriers, scopedDb plus RLS (ADR-007), and a test that attempts cross-tenant access on every entry point.
npm supply chainMediumHighLocked versions, pnpm audit in CI, Renovate with a quarantine delay, mandatory human review for any new dependency, minimal dependencies in core.
CSRF on a Server ActionLowHighNext.js built-in protection, SameSite=Lax + Secure + HttpOnly cookies, origin checking.

13.2 Privacy - the project's commitments

Privacy contract
  • Zero telemetry. No analytics, no "version ping" without explicit consent. If an update check is ever added, it is off by default and documented.
  • Zero third-party assets. Fonts, icons and scripts are served by the instance. An instance cut off from the internet must render perfectly.
  • Enumerable outbound traffic. An "Outbound traffic" screen lists every destination contacted, why, and lets you disable it.
  • Offline mode. ALTITUDE_OFFLINE=true cuts every external call: prices become manual, everything else keeps working.
  • Real erasure. Deleting a household purges rows, files and application backups - not merely a deleted_at flag.

13.3 GDPR for self-hosted software

A frequently misunderstood point: when an individual hosts Altitude for their own household, they generally fall under the household exemption. The project itself is not a data controller, since it receives no data. It must nevertheless equip compliance for shared instances:

Right / obligationWhat Altitude provides
Portability (art. 20)Complete JSON + CSV export, one click, re-importable.
Erasure (art. 17)Real cascading deletion, with a report of what was removed.
Access (art. 15)A "My data" page: what is stored, where, and since when.
MinimisationNo field collected "just in case". Raw import files are purged automatically.
Security (art. 32)Encryption in transit and of secrets, audit log, 2FA, hardening documentation.
Records & processorsA records template in the documentation, plus a list of potential processors (aggregator, quote provider) depending on the chosen configuration.

The container runs as a non-privileged user, with a read-only filesystem except the data volume, no-new-privileges, and Linux capabilities reduced to the strict minimum. A docker-compose.hardened.yml is provided.
