12.2 Le Globe — spécification

Données
  • Une requête serveur renvoie [{ iso2, lat, lng, value, pct, label }], plafonnée à 60 pays ; le reste est regroupé en « autres ».
  • Rayon du marqueur ∝ √(poids) — la surface perçue reste proportionnelle à la valeur.
  • Couleur par région (Amérique du Nord, Europe, Asie-Pacifique, émergents), cohérente avec les autres graphiques d'allocation.
  • Un anneau autour du globe indique la part non transparisée.
  • Centroïdes des pays : jeu de données embarqué (~4 ko), aucun appel réseau.
Contraintes
  • Chargement différé : next/dynamic + IntersectionObserver. Le globe ne doit pas peser sur le rendu initial du dashboard.
  • Réduction de mouvement : si prefers-reduced-motion, rotation désactivée, rendu statique.
  • Accessibilité : un tableau trié équivalent est toujours présent sous le globe, pas caché derrière un onglet. Le globe est décoratif au sens ARIA ; la donnée vit dans le tableau.
  • Repli : si WebGL est indisponible, une carte SVG en projection équirectangulaire prend le relais.
  • Interaction : survol → infobulle pays / montant / pourcentage. Clic → filtre le tableau sur ce pays.
  • Perf : ≤ 16 ms par image sur un portable milieu de gamme ; animation stoppée quand l'onglet est masqué.

12.3 Jetons de design

/* Sémantique, jamais littérale : "gain" et non "green" */
--gain: oklch(0.62 0.15 155);    --loss: oklch(0.58 0.19 25);
--neutral: oklch(0.55 0.02 260); --estimated: oklch(0.72 0.04 260);
/* Classes d'actifs — palette stable, réutilisée par TOUS les graphiques */
--ac-equity --ac-bond --ac-cash --ac-crypto --ac-realestate --ac-alt
  • Un actif garde la même couleur dans le camembert, la courbe empilée, le treemap et le globe. Sans cette règle, l'utilisateur doit relire la légende à chaque graphique.
  • Gain et perte ne reposent jamais uniquement sur la couleur : signe explicite, flèche, et libellé. 8 % des hommes ont une déficience de vision des couleurs rouge-vert.
  • Chiffres en font-variant-numeric: tabular-nums : les colonnes de montants doivent s'aligner.
  • Thème clair et sombre à parité, jamais un thème sombre bricolé par inversion.

12.4 Mode confidentialité

Raccourci Ctrl/⌘ + Shift + H : tous les montants deviennent •••••, pourcentages et graphiques restent lisibles. Indispensable pour une capture d'écran, une démonstration ou un train. L'état persiste par appareil (stockage local) et n'est pas synchronisé.

Sécurité, vie privée, RGPD

Sécurité

Une instance Altitude contient la carte complète du patrimoine d'un foyer. C'est une cible de valeur : le modèle de menace doit être explicite, pas implicite.

13.1 Modèle de menace

13.2 Vie privée — les engagements du projet

Contrat de confidentialité
  • Zéro télémétrie. Pas d'analytics, pas de « ping de version » sans consentement explicite. Si une vérification de mise à jour est ajoutée, elle est désactivée par défaut et documentée.
  • Zéro ressource tierce. Polices, icônes et scripts sont servis par l'instance. Une instance coupée d'Internet doit s'afficher parfaitement.
  • Sorties réseau énumérables. Un écran « Trafic sortant » liste chaque destination contactée, pourquoi, et permet de la désactiver.
  • Mode hors-ligne. ALTITUDE_OFFLINE=true coupe tout appel externe : les prix deviennent manuels, le reste fonctionne.
  • Effacement réel. Supprimer un foyer purge les lignes, les fichiers et les sauvegardes applicatives — pas seulement un drapeau deleted_at.

13.3 RGPD pour un logiciel auto-hébergé

Point souvent mal compris : quand un particulier héberge Altitude pour son foyer, il relève en général de l'exemption domestique. Le projet, lui, n'est pas responsable de traitement puisqu'il ne reçoit aucune donnée. En revanche, il doit outiller la conformité pour les instances partagées :

Droit / obligationCe que fournit Altitude
Portabilité (art. 20)Export intégral JSON + CSV, en un clic, réimportable.
Effacement (art. 17)Suppression réelle et cascadée, avec compte-rendu de ce qui a été supprimé.
Accès (art. 15)Page « Mes données » : ce qui est stocké, où, depuis quand.
MinimisationAucun champ collecté « au cas où ». Les fichiers bruts d'import sont purgés automatiquement.
Sécurité (art. 32)Chiffrement en transit et des secrets, journal d'audit, 2FA, documentation de durcissement.
Registre & sous-traitantsModèle de registre fourni dans la documentation, et liste des sous-traitants potentiels (agrégateur, fournisseur de cotations) selon la configuration choisie.
